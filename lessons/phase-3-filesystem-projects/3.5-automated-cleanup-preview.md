# 3.5 — Automated Cleanup (Preview of Scripting)

## What I learned

Combined `find`, `tar`, and deletion into one manual cleanup sequence:
```bash
find logs/ -name "*.log" -mtime +0 | wc -l              # count what would be affected
tar -czvf logs-archive-$(date +%Y%m%d-%H%M%S).tar.gz logs/*.log   # archive first
find logs/ -name "*.log" -delete                          # delete only after archiving
```

**New:** `find ... -delete` deletes matches directly, simpler than piping to `xargs rm` when no extra flexibility is needed. Best practice: always run the same `find` command *without* `-delete` first, to see exactly what would be affected, before adding it.

**Core realization:** typing this sequence manually works fine once, but doing it correctly every single day, forever, without ever mistyping a path or skipping the archive step, isn't realistic for a human long-term. This is the actual reason scripting exists in DevOps — not to avoid typing, but to remove human error from repetitive, reliability-critical tasks, while a human still designs and reviews the logic once.
