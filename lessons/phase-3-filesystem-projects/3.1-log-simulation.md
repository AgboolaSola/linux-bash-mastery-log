# 3.1 — Simulated Log Directory

## What I learned

Used a Bash loop for the first time to generate 20 fake log files quickly:
```bash
for i in {1..20}; do echo "Log entry for day $i - status OK" > app-day$i.log; done
```
Means "repeat this action once for each number 1 to 20." Full loop syntax comes in Phase 4.

Confirmed file count and folder size:
```bash
find ~/projects/log-simulation/logs -name "*.log" | wc -l   # 20
du -sh .                                                       # 84K
```
`du -sh` (summary) is the more scalable habit over plain `du -h` — without `-s`, a deeply nested folder would print a line per subfolder instead of one clean total.

**Gotcha, again:** `ls` sorted filenames as text (`app-day1, app-day10, app-day11...app-day2`), not numerically — same string-vs-number sorting issue from Phase 2's `sort -n` lesson, showing up in a different tool entirely.
