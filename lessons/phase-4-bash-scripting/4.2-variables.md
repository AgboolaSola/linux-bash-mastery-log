# 4.2 — Variables in Scripts

## What I learned

```bash
name="Sola"                          # NO spaces around = (same rule as alias, Phase 2)
today=$(date +%Y-%m-%d)                # command substitution stored for reuse
log_count=$(find path -name "*.md" | wc -l)
echo "Hello, $name"
```

Confirmed a script can capture real, live data from the actual filesystem (used `find | wc -l` to count my own lesson files) and use it dynamically — not just hardcoded text.

**Gotcha (predicted correctly):** `name = "Sola"` (with spaces) would make Bash try to run `name` as a command instead of an assignment, failing with a "command not found"-style error — identical failure category to the `alias gs= 'git status'` mistake from Phase 2. Same core rule: zero whitespace around `=` in Bash assignment, always.
