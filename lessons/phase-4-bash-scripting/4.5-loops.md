# 4.5 — Loops (for, while)

## What I learned

**for loop**
```bash
for item in list; do
    # commands using $item
done
```
Used with a number range before (Phase 3, `{1..15}`), and now with a file wildcard:
```bash
for file in ~/path/*.log; do
    echo "Found: $file"
done
```

**Gotcha: empty folder + wildcard doesn't mean zero iterations by default.** Ran the file-loop over `app-server/logs/` (genuinely empty after Phase 3 cleanup) and it still printed one line — the literal, unexpanded string `logs/*` itself, treated as if it were a real filename. By default, Bash leaves an unmatched wildcard pattern as literal text rather than expanding it to "nothing." This could cause a script to error out trying to process a filename that was never real.

**Fix:** `shopt -s nullglob` before the loop — makes an unmatched wildcard expand to nothing at all, so the loop correctly runs zero times over a genuinely empty folder. Confirmed this fixed it in my own script.

**while loop**
```bash
count=1
while [ "$count" -le 5 ]; do
    echo "Count is $count"
    count=$((count + 1))
done
```
`$(( ))` = arithmetic expansion (double parens, different from `$( )` command substitution) — needed for real math, otherwise `count + 1` would just be literal text. `-le` = less than or equal to, same operator family as `-gt`/`-eq`.
