# 4.3 — Reading User Input

## What I learned

```bash
read -p "Prompt text: " varname
echo "You entered: $varname"
```
`-p` shows a prompt, pauses execution, and stores whatever's typed into the named variable.

**If no variable name is given** (`read -p "..."` alone), input still gets captured but falls back to a default built-in variable called `REPLY`. Better to always name your own variable — `REPLY` gets overwritten by any subsequent `read` call in the same script, silently losing earlier input if reused.
