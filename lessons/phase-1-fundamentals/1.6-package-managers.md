# 1.6 — Package Managers

## What I learned

A package manager installs, updates, and removes software, handling dependencies automatically. Ubuntu uses `apt`.

```bash
sudo apt update              # refresh the package catalog (installs nothing)
sudo apt upgrade             # actually installs newer versions
sudo apt install <package>   # install something
sudo apt remove <package>    # uninstall something
apt search <term>            # search by name/keyword
```

Key distinction: `apt update` just refreshes the list of what's available — it does not install or upgrade anything itself. Installing without a recent `update` risks installing outdated versions or failing outright.
