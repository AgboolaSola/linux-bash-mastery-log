# 1.1 — Filesystem Hierarchy

## What I learned

Linux organizes everything as one single tree starting at `/` — unlike Windows, which uses separate drive letters. Key folders:
- `/home` — personal user folders (mine is `/home/sola`)
- `/etc` — system-wide config files
- `/var` — logs and changing data (`/var/log` is the first place to check when debugging a crash)
- `/bin`, `/usr/bin` — where installed programs actually live
- `/mnt/c` — where WSL mounts my Windows C: drive into the Linux tree

**Absolute vs relative paths**
- Absolute path: starts from `/`, always points to the same place no matter where I am (e.g. `/home/sola/projects/linux-bash-mastery-log`)
- Relative path: depends on my current location (e.g. `projects/linux-bash-mastery-log` only works if I'm already in `/home/sola`)
