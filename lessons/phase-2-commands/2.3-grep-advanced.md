# 2.3 — grep (searching file contents)

## What I learned

```bash
grep "pattern" filename
grep -r "pattern" directory/   # recursive, searches every file in a folder tree
grep -i "pattern" filename      # case-insensitive
grep -n "pattern" filename      # show line numbers
grep -c "pattern" filename      # count matches
```

`-n` matters a lot at real scale — "found it in config.py" is nearly useless in a large file; "found it in config.py, line 342" lets you jump straight there (`code -g file:342` — needed the `-g` flag to make this work, plain `code file:342` didn't).

## Real DevOps use
`grep -rn "DB_PASSWORD" .` — auditing a whole project for accidentally hardcoded secrets before a commit.
