# 2.5 — wc, tee

## wc
```bash
wc -l filename   # count lines
wc -w filename   # count words
wc -c filename   # count characters/bytes
```
Confirmed manually-counted 27 usernames in `/etc/passwd` matched `wc -l /etc/passwd` exactly.

## tee
Writes output to a file AND still displays it on screen, unlike `>>` which only writes to the file silently.
```bash
ps aux | grep sola | tee sola-processes.txt
```

**Why it matters in real debugging:** if you're diagnosing something live and redirect output quietly with `>>`, you might miss a critical detail (an error, a security issue) until you separately go check the file afterward — costing real time in an urgent situation. `tee` surfaces it immediately while still keeping a permanent record for later review or sharing with a team.

**Confirmed the same self-referencing quirk as `grep` earlier:** `tee sola-processes.txt` showed up as its own line in the very output it was capturing, since it's also a live process at the moment `ps aux` ran.
