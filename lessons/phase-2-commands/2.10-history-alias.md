# 2.10 — history, alias, ~/.bashrc

## What I learned

```bash
history               # full command timeline for this session
history | tail -20
alias gs='git status'  # shortcut, NO spaces around the = or Bash misparses it
```

**Gotcha:** `alias gs= 'git status'` (space after `=`) fails with `command not found`, because Bash sees `alias gs=` as one thing and `'git status'` as a separate command to run immediately — not one alias definition. Whitespace changes parsing meaningfully in Bash, unlike many other languages.

**~/.bashrc** — a plain config file, not a service. Bash automatically reads and runs everything inside it every time a new interactive shell starts, before showing the prompt. Different mechanism from systemd services (which run continuously in the background) — `.bashrc` just gets read once, at shell startup.

Added `alias gs='git status'` to `~/.bashrc`, used `source ~/.bashrc` to reload it into the current session immediately, then confirmed it persisted into a completely new shell session without retyping the alias — proof `.bashrc` runs automatically on every new terminal.
