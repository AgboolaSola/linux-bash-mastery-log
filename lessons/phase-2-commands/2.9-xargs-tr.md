# 2.9 — xargs, tr

## What I learned

**xargs** — takes piped input and feeds it as arguments to a command that doesn't accept piped input directly (like `rm`, `chmod`).
```bash
find . -name "*.bak" | xargs rm
find ~/projects -name "*.bak" | xargs ls -l
```
Bulk operations without manually typing filenames — the real DevOps value is combining `find`'s search power with commands that otherwise only take typed arguments.

Confirmed a real permission block: `find` couldn't look inside `locked-test/` (chmod 000 from Phase 1) — consistent with everything learned about directory `x` permission being required just to enter a folder, still holding true weeks later.

**tr** — translates/replaces individual characters (not whole patterns like `sed`).
```bash
echo "DEBUg = tRue" | tr 'A-Z' 'a-z'   # → debug = true
```
Simpler and faster than `sed` for basic character-level transforms like case conversion.
