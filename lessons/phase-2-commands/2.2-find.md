# 2.2 — find

## What I learned

`find` searches for files/folders recursively, based on criteria like name, type, size, or modification time.

```bash
find <path> -name "pattern"
find <path> -type f          # files only
find <path> -type d          # directories only
find <path> -size +100M      # bigger than 100MB
```

`*` is a wildcard — matches any sequence of characters (including none). Not specific to Linux; the same concept appears in CSS and other tools, just a shared general idea.

**Gotcha:** `find` has no awareness of context — it doesn't know or care "which phase I'm on" or anything beyond literal pattern matching. Searched `phase-*` expecting only phases 0–4 (based on my own progress), but it correctly returned all 7 phase folders (0–6), since I'd created them all upfront in Lesson 0. Good reminder: commands only know exactly what's on disk, nothing implied.

## Real DevOps use
`find /var/log -name "*.log" -size +100M` — a real one-liner for hunting down what's eating disk space on a server.
